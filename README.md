#Statistical and Machine Learning Experiments

This repository contains a collection of statistical analysis and machine learning experiments performed using Python and the Pima Indians Diabetes Dataset. The experiments cover exploratory data analysis, resampling techniques, statistical inference, hypothesis testing, model evaluation, and explainable AI.

# Experiments

## Experiment 1 – Exploratory Data Analysis

This experiment focuses on exploring the Pima Indians Diabetes Dataset using Python. Dataset structure, data types, descriptive statistics, missing values, zero values, outliers, and distributions are analyzed. Visualizations such as histograms, boxplots, correlation heatmaps, and pair plots are used to understand the dataset.

## Experiment 2 – Statistical Inference, Estimation and Hypothesis Testing

This experiment applies statistical inference techniques to the Pima Indians Diabetes Dataset. Point estimation, confidence intervals, hypothesis formulation, t-tests, Chi-Square tests, test statistics, and p-values are studied. The results are interpreted to draw statistical conclusions from sample data.

## Experiment 3 – Regression Model Development and Evaluation

This experiment develops a regression model using the Pima Indians Diabetes Dataset to predict a continuous variable such as BMI. A Linear Regression model is trained and evaluated using MAE, MSE, RMSE, and R². Actual-versus-predicted and residual analysis are also performed.

## Experiment 4 – Machine Learning Model Evaluation and Explainability

This experiment evaluates a Logistic Regression classification model for predicting diabetes outcomes. The model is evaluated using cross-validation, Accuracy, F1-Score, calibration analysis, and Brier Score. SHAP and LIME techniques are used to explain predictions and identify important features.

## Experiment 5 – Bootstrap Sampling and Permutation Testing

This experiment applies bootstrap and permutation resampling techniques to the Pima Indians Diabetes Dataset. Bootstrap sampling is used to estimate sampling distributions and confidence intervals. Permutation testing is performed to compare groups and analyze statistical differences.

## Experiment 6 – Regression Model Development and Evaluation

This experiment focuses on developing and evaluating a machine learning regression model using the Pima Indians Diabetes Dataset. The workflow includes preprocessing, feature selection, train-test splitting, model training, prediction, and performance evaluation. Regression metrics are used to measure the quality of predictions.

## Experiment 7 – Kubernetes Container Deployment and Management

This experiment demonstrates containerized application deployment using Kubernetes. Container images, Pods, deployments, services, and basic Kubernetes management commands are explored. The experiment provides practical understanding of deploying and managing applications in a container orchestration environment.

## Experiment 8 – K-Means Clustering, Elbow Method and PCA

This experiment applies unsupervised learning using the K-Means clustering algorithm. The Elbow Method and Silhouette Score are used to determine and evaluate the appropriate number of clusters. PCA is also applied for dimensionality reduction and visualization of the clustered data.

## Experiment 9 – Logistic Regression Model Evaluation and Explainability

This experiment develops a Logistic Regression classification model to predict diabetes outcomes from the Pima Indians Diabetes Dataset. The model is evaluated using classification metrics such as Accuracy, Precision, Recall, F1-Score, and ROC-AUC. Explainability techniques are used to understand feature contributions and model predictions.
