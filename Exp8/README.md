# Experiment 08 – Clustering and Dimensionality Reduction

## Title

**Apply Clustering and Dimensionality Reduction Techniques for Pattern Discovery**

## Aim

To apply clustering and dimensionality reduction techniques to identify hidden patterns and meaningful groups in the **Pima Indians Diabetes Dataset**.

## Objectives

After completing this experiment, the following objectives were achieved:

1. Applied clustering techniques to discover patterns in the dataset.
2. Applied dimensionality reduction techniques to simplify high-dimensional data.
3. Determined a suitable number of clusters using the Elbow Method.
4. Evaluated clustering performance using the Silhouette Score.
5. Applied Principal Component Analysis (PCA) for dimensionality reduction.
6. Visualized and interpreted the discovered clusters.

## Tools and Technologies Used

* Python 3.x
* Google Colab / Jupyter Notebook
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn

## Dataset

**Dataset:** Pima Indians Diabetes Dataset

The dataset contains diagnostic information for **768 female patients**.

The target variable is:

* `Outcome = 0` → Non-diabetic
* `Outcome = 1` → Diabetic

## Methodology

The experiment follows the workflow:

```text
Dataset
   ↓
Data Preprocessing
   ↓
Feature Selection
   ↓
Data Standardization
   ↓
K-Means Clustering
   ↓
Elbow Method
   ↓
Silhouette Score
   ↓
PCA
   ↓
Visualization
   ↓

```

## Procedure

1. Load and preprocess the Pima Indians Diabetes Dataset.
2. Select the required numerical features for clustering.
3. Handle invalid or missing values in the dataset.
4. Standardize the selected features.
5. Apply the K-Means clustering algorithm.
6. Use the Elbow Method to determine a suitable number of clusters.
7. Evaluate the quality of the clusters using the Silhouette Score.
8. Apply PCA to reduce the feature dimensions.
9. Visualize the clusters using the principal components.
10. Interpret the patterns obtained from the clustering and PCA results.

## Model Used

### K-Means Clustering

K-Means is an unsupervised machine learning algorithm used to divide data into a specified number of clusters.

The algorithm assigns each observation to the nearest cluster centroid and repeatedly updates the centroids until the clusters become stable.

In this experiment, K-Means was used to group patients based on similarities in their medical attributes.

## Cluster Evaluation

The clustering model was evaluated using:

### Elbow Method

The Elbow Method is used to determine a suitable number of clusters.

It calculates the within-cluster sum of squared distances for different values of `k`. The point where the improvement starts decreasing significantly is considered the elbow point.

For this experiment, the Elbow Method was used to select the appropriate number of clusters.

### Silhouette Score

The Silhouette Score measures how well each observation fits within its assigned cluster compared with other clusters.

A higher Silhouette Score generally indicates better-defined and more separated clusters.

The Silhouette Score was calculated to evaluate the quality of the K-Means clustering.

## Dimensionality Reduction

### Principal Component Analysis (PCA)

PCA is a dimensionality reduction technique that transforms the original features into a smaller set of principal components.

The principal components represent the maximum possible variation in the data while reducing the number of dimensions.

In this experiment, PCA was used to reduce the data to two principal components so that the clusters could be visualized graphically.

## Cluster Visualization

The clusters obtained using K-Means were visualized using the principal components generated by PCA.

The visualization helps in understanding the distribution of observations and the relationship between the discovered clusters.

The PCA plot provides a two-dimensional representation of the clustered data.

## Results

The experiment successfully:

* Preprocessed and standardized the dataset.
* Applied K-Means clustering.
* Used the Elbow Method to determine a suitable number of clusters.
* Evaluated the clusters using the Silhouette Score.
* Applied PCA for dimensionality reduction.
* Visualized the clusters using two principal components.
* Identified patterns and groups within the dataset.

## Conclusion

The clustering and dimensionality reduction techniques were successfully applied to the Pima Indians Diabetes Dataset. K-Means was used to identify groups of similar observations, while the Elbow Method and Silhouette Score were used to evaluate the clustering. PCA reduced the dimensionality of the dataset and helped visualize the discovered clusters. The experiment demonstrated how unsupervised learning and dimensionality reduction techniques can be used to discover patterns in machine learning datasets.
